Documenting my progress through [OverTheWire Bandit Levels](https://overthewire.org/wargames/bandit/) which is a war-game focused on linux command-line skills, file permissions, and basic security concepts. Each level has a simple goal to find the password hidden somewhere in the server and the challenge is to figure out what techniques and commands are required for them.

There are 34 levels in total
